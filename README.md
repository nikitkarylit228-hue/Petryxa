# Pixelizer Pro

Превращает любое изображение в матрицу оттенков с **регулируемым размером пикселей** (от 0.5 до 5 см).

## 🎯 Функции
- Загрузка любого фото (JPG, PNG, BMP, WEBP)
- **Регулировка размера пикселя** — ползунок от 0.5 до 5 см
- Каждый пиксель — **крупная цифра 0–9** (от чёрного к белому)
- Копирование матрицы в буфер
- Сохранение матрицы в `.txt`
- Работает на **телефоне, планшете, ПК**
- Можно установить как **PWA-приложение** (на экран)

## 🚀 Как использовать
1. Открой `index.html` в браузере
2. Загрузи фото
3. Меняй размер пикселей ползунком
4. Сохраняй или копируй матрицу

## 📲 Установка как приложение
- **Телефон**: открой в браузере → «Добавить на экран»
- **ПК**: открой в Chrome → три точки → «Установить приложение»
